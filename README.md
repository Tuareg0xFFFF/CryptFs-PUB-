# CryptFs Vault

Public part of CryptFs Vault, an app for iPhone, iPad and Mac that opens and creates encrypted vaults in the [gocryptfs](https://github.com/rfjakob/gocryptfs) format, in iCloud Drive, Dropbox or folders on the device, and shows them in the Files app and Finder.

- [Support](SUPPORT.md): help, bug reports and feature requests
- [Privacy Policy](PRIVACY.md): CryptFs collects no data

Questions and bug reports: [open an issue](https://github.com/Tuareg0xFFFF/CryptFs-PUB-/issues).
